# Billboard Studio

Billboard Studio is a Next.js app for building, managing, and sharing branded quote experiences for promo/product programs. It gives internal account managers an admin workflow to create projects, add item-level pricing and visuals, and share client-facing quote views and PDFs.

## What this project does

- Manages projects and items with pricing tiers, product details, and image assets.
- Supports admin-authenticated workflows for creating and maintaining quote content.
- Generates client-friendly quote pages and downloadable PDF exports.
- Includes an art approval workflow with allowlisted client access, review rounds, and decision capture.
- Uses Supabase for auth, data, and storage-backed file handling.
